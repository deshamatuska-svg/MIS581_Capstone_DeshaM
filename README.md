# Program-Level Enrollment Structure Trends in U.S. Four-Year Institutions

## Overview
This repository contains the materials for my MIS581 Portfolio Project and Capstone in Business Intelligence and Data Analytics at Colorado State University Global.

The project applies longitudinal enrollment analytics using IPEDS Fall Enrollment by Major Field of Study (EF‑CP) data to examine how enrollment structure varies across academic programs and student composition categories within U.S. four‑year institutions. The analysis is framed for higher education assessment providers and focuses on translating enrollment patterns into decision‑support insights rather than causal explanations.

The repository includes the final research paper, supporting analysis outputs, and SAS code used for data preparation and analysis.

---

## Project Objectives
The primary objectives of this project were to:
- Examine program‑level enrollment differences across selected academic program categories
- Evaluate enrollment structure differences by student level (undergraduate vs. graduate)
- Evaluate enrollment structure differences by attendance status (full‑time vs. part‑time)
- Analyze enrollment trends over time using longitudinal administrative data
- Translate statistical findings into actionable insights relevant to higher education assessment providers

---

## Data Source
The analysis uses data from the **Integrated Postsecondary Education Data System (IPEDS)**:
- Fall Enrollment by Race/Ethnicity – Major Field of Study (EF‑CP)
- Reporting years: 2016, 2018, 2020, 2022, and 2024
- Unit of analysis: program‑level enrollment records within U.S. four‑year institutions

All data used are aggregated, publicly available, and non‑identifiable.

## Analytical Methods
The project applies:
- Descriptive statistics
- Longitudinal trend analysis
- Generalized Linear Modeling (GLM)

Statistical interpretations are presented using hypothesis‑testing language (rejecting or failing to reject null hypotheses) and are explicitly framed as comparative structural signals rather than causal claims.

---

## Key Findings (High-Level)
- Mean enrollment differs statistically across program categories examined.
- Enrollment structure differs significantly by attendance status and student level.
- Program‑by‑attendance interactions are statistically significant, indicating structural differences across programs.
- Program‑specific differences in enrollment change over time were not statistically detectable within the analytic scope.
- Enrollment disruption is structurally differentiated rather than uniform across programs and student populations.

Detailed results and interpretation are provided in the final paper and supporting analysis outputs.

---

## Ethical Considerations
All analysis was conducted using aggregated administrative data. Results are presented with careful attention to:
- Responsible interpretation
- Avoidance of deficit‑oriented or ranking‑based conclusions
- Appropriate contextualization of statistical significance

The project emphasizes enrollment segmentation as a decision‑support tool rather than a measure of program quality.
