# Program-Level Enrollment Structure Trends in U.S. Four-Year Institutions

## Project Overview
This repository contains the materials for my MIS581 Portfolio Project and Capstone at Colorado State University Global. The project applies program‑level enrollment analytics using IPEDS Fall Enrollment by Major Field of Study (EF‑CP) data to examine how enrollment structure differs across academic programs and student populations within U.S. four‑year institutions.

The analysis is framed for higher education assessment providers and focuses on enrollment patterns as decision‑support signals rather than causal explanations.

---

## Data Source
- Integrated Postsecondary Education Data System (IPEDS)
- Fall Enrollment by Major Field of Study (EF‑CP)
- Reporting years: 2016, 2018, 2020, 2022, and 2024
- Aggregated, publicly available institutional data

## Analytical Approach
The project uses descriptive statistics, longitudinal trend analysis, and generalized linear modeling (GLM) to evaluate enrollment differences by program category, student level, and attendance status.

Results are interpreted as comparative structural patterns to support segmentation and strategic decision‑making.
